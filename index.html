Conhecendo o CSS

O que é CSS ?

CSS : Significa Cascading Style Sheets, ou, em portugues, Folhas de estilo em cascata.

É a linguagem responsável por definir a apresentação visual de um documento HTML.

Como trabalhar com o CSS ?

Existem tres formas clássicas de colocar o CSS em um arquivo HTML:

  • CSS Inline
  • CSS Interno
  • CSS externo

Conhecendo o CSS Inline

Nessa abordagem, o CSS é colocado diretamente no elemento HTML através de um atributo chamado de style
